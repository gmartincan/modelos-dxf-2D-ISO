# modelos-dxf-2D-ISO
Repositorio de vistas de piezas en formato dxf
La intención de este repositorio es la de generar una base de datos contrastada de vistas ortogonales de modelos de piezas.
Todas las piezas son poliédricas y están representadas en formato ISO con tres vistas, preferentemente alzado, planta y vista lateral izquierda.
Sólo se usan tipos de línea continua y oculta por lo que no se representan ejes ni textos o cotas.
